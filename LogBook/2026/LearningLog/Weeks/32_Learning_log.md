##### Hoy aprendí

**recorrido básico de una comunicación en Internet** 
+ 1. El cliente obtiene la IP mediante DNS. 
		+ 2. Se conecta a la IP y al puerto del servidor.
			+ 3. Los datos viajan usando un protocolo de transporte (TCP o UDP).
				+ 4. Sobre ese transporte funcionan protocolos de aplicación como HTTP, HTTPS, SMTP o FTP, que definen el formato y el significado de los mensajes que intercambian las aplicaciones. 

**HTTP**
+ mecanismos adicionales que permiten que el servidor identifique al usuario entre distintas solicitudes, evitando iniciar sesión constantemente.
	+ Cookies.
	+ Tokens.
	+ Sesiones.
+ **HTTP/3** Es la versión más moderna.

+ **HTTPS** 
	+ **HTTP** `+` **TLS** (_Seguridad_) = _**HTTPS**_
+ Con **HTTPS**: 
	+ Usuario → `Información cifrada` → Internet → Servidor
